## My nvim config

this is my person neovim config, originally inspired by [BreadOnPenguins](https://github.com/BreadOnPenguins/nvim) config.

### install

1. clone into nvim config folder

2. run `:PlugInstall` inside nvim to install

### common keybinds

* S-j buffer left
* S-k buffer right

* <spsace>ff file search
* <space>fg grep
